# 繰り返し・和音・連符・マクロ

[← 目次に戻る](syntax.md)

同じフレーズを繰り返したり、まとめて書くための記法です。

## 繰り返し `[ ]` `:`

```
[回数 演奏内容]
```

```
[4 cde]         // cde を4回繰り返す
[cde]           // 回数を省略すると2回
```

`:` を書くと、**最後の回だけ** `:` 以降を飛ばして繰り返しを抜けます。
1番カッコ・2番カッコのような書き方ができます。

```
[4 cde:g]e      // 1～3回目は cdeg、4回目は cde を演奏してから e へ
```

繰り返しはネストできます。

```
[2 c [3 de] f]
```

回数に0を指定すると、警告が出たうえで1回として実行されます。

## 和音 `' '`

シングルクォートで囲んだ音符を同時に鳴らします。

```
'和音'[音長][,ゲート][,ベロシティ]
```

```
'ceg'           // ド・ミ・ソの和音
'ceg'8          // 8分音符の和音
'ceg'4,90,120   // 音長4、ゲート90、ベロシティ120
'ceg'4,%70      // ゲートを70ステップにする(%を付けるとステップ単位)
'c>c'           // オクターブ違いの和音も書ける
```

```
l4 'ceg' 'dfa' 'egb' 'ceg'
```

日本語(ストトン表記)では `「ドミソ」` と書けます。

> サクラv1/v2にあった `c0e0g` という書き方はサポートしていません。

## 連符 `{ }` / `Div`

カッコ内の音符を、指定した長さの中に均等に詰めて演奏します。3連符・5連符などに使います。

```
{音符...}[音長]
Div{音符...}[音長]
```

```
l4 {cde} f {gab} >c<        // 4分音符の中に3つ詰める(3連符)
Div{ceg}4
{cde}2                      // 2分音符の中に3つ
```

`^` も1音として数えるので、リズムを崩した連符が書けます。

```
l4 {cde}c {gfe}d {c^d} e {d^e} f
```

連符はネストできます。

```
l1 { c d {efe} d } c
```

| コマンド | 別名 |
|---|---|
| `Div{ ... }` | `DIV` / `{ ... }`(省略形) |

## マクロ(文字列変数)

MMLの断片に名前を付けて、あとから展開できます。
`#名前 = {...}` と `Str 名前 = {...}` は同じ意味です。

```
// 定義
STR P1 = {cdefg}
#P1 = {cdefg}

// 展開
P1
#P1
```

マクロ名は大文字で始めます。

### 引数付きマクロ

マクロの中に `#?1` `#?2` `#?3` … を書いておくと、
展開時に渡した引数で置き換えられます。

```
// 定義
#Unison = { Key=#?2 Sub{ #?1 } Key=0 #?1 }
// 展開
#Unison{cde},7
```

引数はカッコでも波カッコでも渡せます。

```
Str Foo = { o#?1 cde }
Foo(5)
Foo{5}
```

### 定義済みマクロ

| マクロ | 内容 | 定義 |
|---|---|---|
| `OctaveUnison{...}` | オクターブユニゾンを演奏 | `Sub{> #?1 <} #?1` |
| `Unison5th{...}` | 5度のユニゾンを演奏 | `Sub{ Key=7 #?1 Key=0 } #?1` |
| `Unison3th{...}` | 3度のユニゾンを演奏 | `Sub{ Key=4 #?1 Key=0 } #?1` |
| `Unison{...},n` | n度のユニゾンを演奏 | `Sub{ Key=#?2 #?1 Key=0 } #?1` |
| `RndTiming(n)` | 発音タイミングをランダムにする | `t.Random(#?1)` |

```
OctaveUnison{cde}
Unison{cde},7
```

## リズムマクロ `$` / `Rhythm`

ドラムパートを1文字1命令で書くためのモードです。
`Rhythm{ ... }` の中では、大文字・小文字に関わらず1文字が1つの命令として展開されます。

```
CH(10)
Rhythm{
    [4 l8
        bhsh bhsh
        hoho hoho
    ]
}
```

| コマンド | 別名 |
|---|---|
| `Rhythm{ ... }` | `RHYTHM` `R` `Rythm` `RYTHM`(綴りミスも互換のため使える) |

丸カッコ `( )` の中身は置換されません。`Sub` はそのまま `Sub` として扱われます。

### 定義済みリズムマクロ

| 文字 | 展開結果 | 音 |
|---|---|---|
| `b` | `n36,` | バスドラム |
| `s` | `n38,` | スネアドラム |
| `h` | `n42,` | クローズハイハット |
| `m` | `n46,` | オープンハイハット |
| `o` | `n46,` | オープンハイハット |
| `c` | `n49,` | シンバル |
| `H` | `n50,` | ハイタム |
| `M` | `n47,` | ミッドタム |
| `L` | `n43,` | ロータム |
| `_` | `r` | 休符 |

### リズムマクロの定義

```
$文字{ 定義 }
```

```
$S{n37,}        // 新しく定義
$b{n36,}        // 定義済みのものを再定義することもできる
```

定義できるのは文字コード 0x40～0x7F の1文字(`@` `A`～`Z` `[` `\` `]` `^` `_` `` ` `` `a`～`z` `{` `|` `}` `~`)です。
