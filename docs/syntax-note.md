# 音符と演奏パラメータ

[← 目次に戻る](syntax.md)

音符そのものと、音符に影響するパラメータ(音長・オクターブ・音量・ゲート・タイミング)を説明します。

## 音名 `c d e f g a b`

`cdefgab` が「ドレミファソラシ」に対応します。

```
cdefgab
```

### 書式

```
c[臨時記号][音長][,ゲート][,ベロシティ][,タイミング][,オクターブ][&]
```

引数は前から順に指定します。途中を飛ばすことはできません(`,` を並べる必要があります)。

| 位置 | 内容 | 省略時 |
|---|---|---|
| 臨時記号 | `+` `#` で半音上げ、`-` で半音下げ、`*` でナチュラル(調号を無視) | なし |
| 音長 | `4` `8.` `%48` `4^8` など | 直前の `l` の値 |
| ゲート | 百分率。`q` と同じ意味。`%48` と書くとステップ単位 | 直前の `q` の値 |
| ベロシティ | 0～127。`v` と同じ意味 | 直前の `v` の値 |
| タイミング | ステップ単位のずれ。`t` と同じ意味 | 直前の `t` の値 |
| オクターブ | その音だけのオクターブ | 直前の `o` の値 |

```
c4              // 4分音符のド
c+              // ド♯
c-              // ド♭
c*              // 調号(KeyFlag)を無視したド
c8,90,120       // 8分音符、ゲート90%、ベロシティ120
c4,,100         // ゲートは省略、ベロシティ100
c4,,,,6         // オクターブ6のド
c%96,%70,120,0  // 音長96ステップ、ゲート70ステップ、ベロシティ120、タイミング0
```

音長と同じように、ゲートも `%` を付けるとステップ単位の指定になります
(詳しくは [ゲートタイム `q`](#ゲートタイム-q) を参照)。`c%96,%70,120,0` は
`l%96 q%70 v120 t0 c` と同じ意味です。

臨時記号は複数書けます。`c++` はダブルシャープ(半音2つ上)です。

## 番号指定の音符 `n`

MIDIのノート番号を直接指定します。ドラムパートを書くときによく使います。

```
n(番号)[,音長][,ゲート][,ベロシティ][,タイミング][&]
```

```
n60         // ノート番号60 (中央のド)
n$3C        // 16進数でも書ける
n36,4,90,120
n36,4,%70   // ゲートを70ステップにする
```

音名 `c` は `o5` のとき番号60になります(`o4 c` は48)。

## 休符 `r`

```
r           // 現在の音長ぶん休む
r4          // 4分休符
r%48        // 48ステップ休む
r-4         // 4分音符ぶんタイムポインタを戻す
```

`r-` のように `-` を付けると、タイムポインタを**戻し**ます。
和音を重ねたり、書き込み位置を微調整するときに使えます。

## 音長 `l`

以降の音符・休符の既定の長さを指定します。

```
l4          // 4分音符
l8          // 8分音符
l16         // 16分音符
```

### 音長の書式

| 書き方 | 意味 |
|---|---|
| `4` | 4分音符(n分音符の n を書く) |
| `4.` | 付点4分音符(1.5倍) |
| `4..` | 複付点(1.75倍) |
| `4...` | 三付点(1.875倍) |
| `4....` | 四付点(1.9375倍) |
| `%48` | ステップ(Tick)数で直接指定 |
| `4^8` | タイで連結した長さ(4分音符 + 8分音符) |
| `4+8` | `^` と同じ(`+` も使える) |
| `^` | 数値を省略すると既定の音長ぶん足す |
| `!4` | 引数の中で使う書式。4分音符の長さをステップ数の値として返す |

タイムベースが96のとき、`l4` は96ステップ、`l8` は48ステップです。
ステップ数は `タイムベース * 4 / n` で計算されます。

`%` によるステップ指定は、書いたその場所だけに効きます(モードは切り替わりません)。

```
// 以下の2行は同じ意味
l%96 cde
c4d4e4
```

### 音長の先行指定

| 書き方 | 内容 |
|---|---|
| `l.onNote(v1,v2,...)` / `l.N(...)` | 音符ごとに音長を順番に切り替える |
| `l.onCycle(step,v1,v2,...)` / `l.C(...)` | `step` ステップごとに音長を切り替える |
| `l.onTime(low,high,len,...)` / `l.T(...)` | 時間経過に沿って音長を推移させる |
| `l.Random(n)` | 音長を n の幅でランダムにばらつかせる |

そのほかの共通オプションは[先行指定(リザーブ)](syntax-reserve.md)を参照してください。

## 音符属性に共通の先行指定

`v` `q` `t` `o` `l` では、値をあらかじめまとめて予約する「先行指定」を共通して使えます。

| 書き方 | 内容 |
|---|---|
| `.onNote(v1,v2,...)` / `.N(...)` | 音符ごとに値を順番に切り替える |
| `.onTime(low,high,len,...)` / `.T(...)` | 時間経過に沿って値を推移させる |
| `.onCycle(step,v1,v2,...)` / `.C(...)` | `step` ステップごとに値を切り替える |
| `.Random(n)` `.Range(low,high)` `.Delay(n)` `.Repeat(on/off)` | 書き込む値や位置の調整 |
| `.Max(n)` | 値の上限を変更する(`v` `q` のみ) |

書式と詳しい動作は[先行指定(リザーブ)](syntax-reserve.md)を参照してください。

## 音符属性の相対指定 `+n` `++` `--`

`v` `q` `t` `o` は、現在の値からの相対指定ができます。

| 書き方 | 内容 |
|---|---|
| `v+10` | 現在の値に10を足す(`q+10` `o+1` `t+3` も同様) |
| `v++` `v+` | 既定の増減幅だけ上げる(増減幅は `v`=vAdd, `q`=qAdd, `o` `t`=1) |
| `v--` `v-` | 既定の増減幅だけ下げる |
| `v-10` | 相対指定ではなく、負の数値の指定として扱う(従来通り) |

```
v40 v+10 c      // ベロシティ50
o5 o+2 c        // オクターブ7
q90 q-- c       // qAdd(初期値1)だけ下げて89
```

> マイナス符号に数値が続く `v-10` `t-10` `o-5` は、これまでのMMLとの互換性のため
> 相対指定ではなく数値の指定になります。相対的に下げるときは `v--` と書いてください。
> なお、増減幅に変数を使うときは `v+(A)` のようにカッコで囲みます。

## 音符属性の引数の書き間違い

`v` `q` `t` `o` に引数がないときはエラーになります
([#78](https://github.com/kujirahand/sakuramml-rust/issues/78))。

```
v100 vf+4       // [ERROR] コマンドに引数がありません: "v"
```

上の例は `vf+4` が `f+4` の書き間違いです。エラーになっても引数は読み飛ばさないので、
続く `f+4` は音符として演奏され、ベロシティは直前の値のままになります。
変数を引数にするときは、定義済みの変数名をそのまま書くか、`v=A` `v(A)` と書いてください。


## オクターブ `o` `>` `<` `` ` `` `"`

```
o5          // オクターブ5 (範囲: 0～10)
o+1         // オクターブを1つ上げる(相対指定 / o++ も同じ)
>           // オクターブを1つ上げる
<           // オクターブを1つ下げる
`           // 次の音符だけオクターブを1つ上げる
"           // 次の音符だけオクターブを1つ下げる
```

```
o4 cdefgab>c<bagfedc
o4 c `c "c c        // 3番目は1つ上、4番目は1つ下
```

### オクターブの先行指定

| 書き方 | 内容 |
|---|---|
| `o.Random(n)` | オクターブを n の幅でランダムにばらつかせる(おおよそ ±n/2) |
| `o.onNote(v1,v2,...)` / `o.N(...)` | 音符ごとにオクターブを切り替える |
| `o.onCycle(step,v1,v2,...)` / `o.C(...)` | `step` ステップごとにオクターブを切り替える |
| `o.onTime(low,high,len,...)` / `o.T(...)` | 時間経過に沿ってオクターブを推移させる |

## 音量(ベロシティ) `v` `(` `)`

```
v100        // ベロシティ100 (範囲: 0～127)
v++         // vAddの値だけ上げる
v--         // vAddの値だけ下げる
v+10        // 現在の値から10だけ上げる
)           // vAddの値だけ上げる (v++ と同じ)
(           // vAddの値だけ下げる (v-- と同じ)
System.vAdd(3)  // ( ) や v++ v-- の増減幅を3にする (初期値: 8)
```

```
v127 c ( c ( c (( c )) c ) c ) c
```

> `vAdd` `qAdd` は小文字の `v` `q` で始まるため、そのままでは音量・ゲート指定として
> 解釈されてしまいます。`System.vAdd(3)` `System.qAdd(3)` と書いてください。

### 音量の先行指定

| 書き方 | 内容 |
|---|---|
| `v.Random(n)` | ベロシティを n の幅でランダムにばらつかせる(おおよそ ±n/2) |
| `v.onTime(low,high,len,...)` / `v.T(...)` | 時間経過に沿ってベロシティを変化させる |
| `v.onNote(v1,v2,...)` / `v.N(...)` | 音符ごとにベロシティを順番に切り替える |
| `v.onCycle(step,v1,v2,...)` / `v.C(...)` | `step` ステップごとにベロシティを切り替える |
| `v.Max(n)` | ベロシティの上限を変更する(初期値: 127) |

```
v.onTime(0,127,!1) l8 cccccccc      // 全音符の間に0から127へ変化
v.onNote(120,80,100,80) cdef
```

### サブベロシティ `v__n`

`v__n` は、通常のベロシティへ加算する独立した補正レイヤーです。`n` には0以上の
レイヤー番号を指定します。複数のレイヤーが有効な場合は、すべての値を加算します。

```
v70 v__1(-10) v__3(20) c    // 70 - 10 + 20 = 80
v__1(0) d                    // レイヤー1だけ解除: 70 + 20 = 90
```

固定値の範囲は `-127～127` です。通常の `v`、音符に直接指定したベロシティ、
`v.onTime`・`v.onNote`・`v.onCycle`、`v.Random` を計算したあとにサブベロシティを
加算し、最終的なMIDIベロシティを `0～127` に収めます。音名 `cdefgab` と番号指定の
音符 `n(...)` の両方に適用されます。

サブベロシティにも先行指定を使用できます。

| 書き方 | 内容 |
|---|---|
| `v__n.Random(width)` | レイヤーnへ幅 `width` のランダム補正を加える（おおよそ ±width/2） |
| `v__n.onTime(low,high,len,...)` / `v__n.T(...)` | レイヤーnの補正値を時間経過に沿って変化させる |
| `v__n.onNote(v1,v2,...)` / `v__n.N(...)` | レイヤーnの補正値を音符ごとに順番に切り替える |
| `v__n.onCycle(step,v1,v2,...)` / `v__n.C(...)` | レイヤーnの補正値を `step` ステップごとに切り替える |

```
v70 v__1.onCycle(!4,10,-10) cdef  // 80, 60, 80, 60 (4分音符ごと)
v70 v__1.onTime(0,20,!4) l8 ccc   // 70, 80, 70
```

- `onNote` は値を一度ずつ使用し、末尾に達したあとは最後の補正値を維持します。
  `v.Repeat(on)` を指定すると、先頭へ戻ってくり返します。
- `onCycle` は `step` ステップごとに値を切り替え、解除するまでくり返します。
- `onTime` の終了後は、そのレイヤーの直前の固定値へ戻ります。初期値は0です。
- `onTime` の区間長が0以下の組は無視します。
- `v__n(value)` を指定すると、同じレイヤーの先行指定を解除して固定値に戻します。
- `v__n.Random(0)` を指定すると、そのレイヤーのランダム補正だけを解除します。
- 通常の `v.onTime`・`v.onNote`・`v.onCycle` とサブレイヤーの先行指定は独立して動作します。
- 通常の `v.Random` と複数の `v__n.Random` は独立して計算され、すべてのランダム補正を加算します。
- `v.Range` `v.Delay` `v.Repeat` `v.Max` はレイヤー別ではなく `v` 全体に効きます
  (`v__1.Delay(...)` と書いても `v.Delay(...)` と同じ扱いになります)。

## ゲートタイム `q`

音符の長さに対して、実際に発音する割合(百分率)を指定します。

```
q90         // 音長の90%だけ発音する
q100        // 音符の長さいっぱいに発音する
q++         // qAddの値だけ上げる
q--         // qAddの値だけ下げる
q+10        // 現在の値から10だけ上げる
System.qAdd(3)  // q++ q-- の増減幅を3にする (初期値: 1)
```

### ステップ単位のゲート指定 `q%n`

`%` を付けると、割合ではなくステップ数でゲート長を指定します。音長を変えても
発音時間は変わらないので、スタッカートなどの長さを揃えたいときに便利です。

```
TimeBase(96)
l4 q%96 cdef    // 音長いっぱい(96ステップ)発音する
q%48 cdef       // 音長に関わらず48ステップだけ発音する
q%10 cdef       // 10ステップだけ発音する(スタッカート)
q50 cdef        // 通常の数値を書くと割合指定に戻る
q%!8 cdef       // !n の音長表記でステップ数を指定することもできる
q%(A) cdef      // 変数や式でも指定できる
```

音符に付随するゲート指定でも同じように書けます。

```
c%96,%70,120,0  // ゲートは70ステップ
n60,4,%70       // n コマンドでも同じ
'ceg'4,%70      // 和音でも同じ
```

指定した値の扱いは次の通りです。

| 値 | 動作 |
|---|---|
| `q%n` (n > 0) | n ステップだけ発音する。音長を超える値も指定できる(次の音符と重なる) |
| `q%0` | ゲート長0。発音時間のない音符になる |
| `q%-n` | 現在の `q` の値から n を引いたステップ数にする(相対指定)。0未満にはならない |

`q%-n` はオリジナル(Pascal版)と同じ相対指定です。`q` の初期値は90なので、
`q%-1` は89ステップになります。音符に付随するゲート指定 (`c4,%-6` など) も同様に、
そのときの `q` の値からの相対指定として扱います。

```
q80 q%-1 c      // 80 - 1 = 79ステップ
q80 q%-1 c q%-1 d   // 79ステップ、78ステップ (相対指定はくり返し適用される)
```

> ステップ指定は割合ではないため、`q.Max` `q.Range` による上限・範囲の制限は
> 適用されません(`q.Random` は適用されます)。また `q.onTime` `q.onNote`
> `q.onCycle` の先行指定は割合指定なので、有効な間はステップ指定より優先されます
> (音符や和音に付随するステップ指定よりも優先されます)。

### ゲートの先行指定

| 書き方 | 内容 |
|---|---|
| `q.Random(n)` | ゲートを n の幅でランダムにばらつかせる(おおよそ ±n/2) |
| `q.onNote(v1,v2,...)` / `q.N(...)` | 音符ごとにゲートを切り替える |
| `q.onCycle(step,v1,v2,...)` / `q.C(...)` | `step` ステップごとにゲートを切り替える |
| `q.onTime(low,high,len,...)` / `q.T(...)` | 時間経過に沿ってゲートを推移させる |
| `q.Max(n)` | ゲートの上限を変更する(初期値: 100) |

## 発音タイミング `t`

音符を書き込む位置を、ステップ単位で前後にずらします。人間らしいノリを出すのに使います。

```
t-1         // 1ステップ早く発音する
t3          // 3ステップ遅く発音する
t0          // ずらさない
t+3         // 現在の値から3ステップ遅くする(相対指定)
```

### タイミングの先行指定

| 書き方 | 内容 |
|---|---|
| `t.Random(n)` | タイミングを n の幅でランダムにばらつかせる(おおよそ ±n/2) |
| `t.onNote(v1,v2,...)` / `t.N(...)` | 音符ごとにタイミングを切り替える |
| `t.onCycle(step,v1,v2,...)` / `t.C(...)` | `step` ステップごとにタイミングを切り替える |
| `t.onTime(low,high,len,...)` / `t.T(...)` | 時間経過に沿ってタイミングを推移させる |

`RndTiming(3)` は `t.Random(3)` と同じ意味のマクロです。

> 現在の実装では、`t.Random` を直接書くと後続の7文字が読み飛ばされてしまいます
> ([#83](https://github.com/kujirahand/sakuramml-rust/issues/83))。`RndTiming(3)` を使ってください。

## タイ・スラー `&` `^`

### タイ `^`

同じ高さの音を伸ばすときは、音長の中に `^` を書きます。

```
l4 c^^^      // 全音符ぶん伸ばしたド
c4^8         // 4分音符 + 8分音符
```

### スラー `&`

異なる高さの音をつなぐときは `&` を使います。動作は `Slur` コマンドで切り替えられます。

```
c&d         // ドとレをつなぐ
```

```
Slur(モード[, 値[, レンジ]])
```

| モード | 定数 | 動作 | 値の意味 | レンジの意味 |
|---|---|---|---|---|
| 0 | `SLUR_PORT` | グリッサンド。ノートオンをポルタメントでつなぐ | グリッサンドの長さ | ベンドレンジ(省略可) |
| 1 | `SLUR_BEND` | ベンド。異なる音程をピッチベンドで表現(ギターのハンマリングに近い) | 無効 | 無効 |
| 2 | `SLUR_GATE` | `&` の付いた音符のゲートを指定値にする | ゲートの長さ | 無効 |
| 3 | `SLUR_ALPE` | `&` でつないだ音符の終わりまでゲートを伸ばす(アルペジオ) | 最大発音音数 | 無効 |

```
Slur(SLUR_BEND) c&d&e
Slur(SLUR_GATE, 100) c&d&e      // 第2引数はモードに応じた値(SLUR_GATEならゲート値)
Slur(SLUR_PORT, !8) c&d&e       // 第2引数には !8 のような音長表記も使える
Slur(SLUR_PORT, !8, 2) c&e&g    // 第3引数でベンドレンジを2半音に指定 (BR(2) と同じ)
Slur(SLUR_ALPE, 3) l16 c&e&g&>c // 同時に鳴る音を3音までに制限する
```

第3引数(レンジ)を指定すると、`Slur` を書いた位置でベンドレンジが設定されます
(`BR` コマンドで指定するのと同じです)。あとから `BR` で変更すれば、そちらが優先されます。
省略した場合は、`BR` の設定値、`BR` も未指定なら12半音が使われます。

`SLUR_ALPE` で最大発音音数を指定すると、(指定数-1)個あとの音符のゲートの終わりまで
音が伸びます。これにより、同時に鳴る音を指定数までに抑えつつ、
音符ごとのゲート比率(`q`)を保てます。省略時は制限なしで、
`&` でつないだすべての音が最後まで伸びます。

なお、省略した引数は以前に指定した値がそのまま使われます
(例: `Slur(3,2)` のあとに `Slur(3)` と書いても最大発音音数は2のままです)。

## 調号 `KeyFlag`

曲の調(シャープ・フラット)を設定します。以降の音名に自動で適用されます。

```
KeyFlag+(cf)        // ドとファにシャープ (ニ長調)
KeyFlag-(be)        // シとミにフラット (変ロ長調)
KF#(cf)             // '#' は '+' と同じ
KeyFlag=(0,0,1,0,0,1,0)  // 数値指定 (順序は a,b,c,d,e,f,g)
```

| 書式 | 意味 |
|---|---|
| `KeyFlag[=][+ or -](音名...)` | 指定した音名にシャープ/フラットを付ける。音名は区切らずに並べる(`(cf)`) |
| `KeyFlag=(n,n,n,n,n,n,n)` | 数値で指定する。順序は a, b, c, d, e, f, g |

音符側に `*` を付けると、その音だけ調号を無視します。

```
KeyFlag#(c) c c*    // 1つ目はド♯、2つ目はナチュラルのド
```
