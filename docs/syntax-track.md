# トラック・チャンネル・タイムポインタ

[← 目次に戻る](syntax.md)

複数のパートを重ねて演奏するための仕組みを説明します。

## トラックとチャンネル

サクラの曲は複数の**トラック**からできています。
各トラックは独自の**タイムポインタ**(書き込み位置)と、音長・音量・オクターブなどの状態を持ちます。

```
TR(1) CH(1) o5 l4 cdef
TR(2) CH(2) o3 l1 c
```

| コマンド | 別名 | 内容 |
|---|---|---|
| `Track(n)` | `TRACK` `TR` | カレントトラックを変更する(範囲: 0～999) |
| `Channel(n)` | `CHANNEL` `CH` | カレントトラックのMIDIチャンネルを設定する(範囲: 1～16) |
| `Port(n)` | `PORT` | ポート番号を設定する |

チャンネルの初期値はトラック番号と同じです(`TR(1)` ならチャンネル1、`TR(2)` ならチャンネル2)。
トラック0のチャンネルは1です。
ドラムを鳴らすときは `CH(10)` を指定します。

`TR` `CH` は計算式の中では現在の値を返します。

```
Int TrNo = TR      // 現在のトラック番号
Int ChNo = CH      // 現在のチャンネル番号
```

> 変数名にはコマンド名(予約語)を使えません。`CC` `T` `S` `R` `P` `V` `M` などは
> コマンドとして予約されているため、変数名には使えない点に注意してください。

## タイムポインタ `Time`

タイムポインタは「次に音符を書き込む位置」です。音符を書くたびに進みます。
`Time` を使うと任意の位置に移動できます。

```
Time(小節:拍:ステップ)
Time(ステップ数)
```

小節と拍は1から数えます。ステップは0からです。

```
Time(1:1:0) cdef        // 曲の先頭
Time(2:1:0) cdef        // 2小節目の頭
Time(0)                 // ステップ数0 (曲の先頭)
```

引数が1つのときは、そのままステップ数として扱われます。
引数が3つのときは、拍子とタイムベースから位置を計算します。

```
位置 = (小節 - 1) × (タイムベース × 4 ÷ 拍子の分母) × 拍子の分子
     + (拍 - 1) × (タイムベース × 4 ÷ 拍子の分母)
     + ステップ
```

`Time` は計算式の中では現在のタイムポインタ値を返します(`TIME` `TIMEPOS` `TIMEPTR` も同じ)。

### 小節番号のずらし `MeasureShift`

`Time` で指定した小節番号に、指定した値を加えます。イントロを後から足すときなどに便利です。

```
MeasureShift(1)     // 以降の Time(n:1:0) が1小節ぶん後ろにずれる
```

| コマンド | 別名 |
|---|---|
| `MeasureShift(n)` | `System.MeasureShift` `MEASURE_SHIFT` |

### タイムポインタの同期 `TrackSync`

全トラックのタイムポインタを、カレントトラックの位置に合わせます。

```
TrackSync
```

| コマンド | 別名 |
|---|---|
| `TrackSync` | `TRACK_SYNC` |

### タイムベース `TimeBase`

4分音符あたりのステップ数(分解能)です。初期値は96です。

```
TimeBase(96)
```

| コマンド | 別名 |
|---|---|
| `TimeBase(n)` | `System.TimeBase` `Timebase` `TIMEBASE` |

- 48以下を指定すると48に補正されます。
- 定数のみ指定できます(変数や計算式は使えません)。
- 音符を書き込んだ後に変更すると警告が出ます。曲の先頭で指定してください。

## サブ演奏 `Sub`

`Sub{...}` のブロックを実行した後、タイムポインタを `Sub` の直前の位置に戻します。
同じトラックに和音や対旋律を重ねるときに使います。

```
Sub{ cdef  c }
Sub{ efga  e }
     rrrr  g
```

| コマンド | 別名 |
|---|---|
| `Sub{ ... }` | `SUB` `S` |

## 複数トラックの同時演奏 `Play`

複数のトラックに、変数(マクロ)で定義したMMLを一度に流し込みます。
引数の1番目がトラック1、2番目がトラック2…に割り当てられます。

```
Str AA = { o5 l4 cdef }
Str BB = { o3 l1 c }
Str DD = { CH(10) l8 n36 n38 n36 n38 }
Play(AA, BB, DD)
```

| コマンド | 別名 |
|---|---|
| `Play(A,B,C,...)` | `PLAY` |

各トラックは `Play` を書いた時点のタイムポインタから始まり、
実行後は全トラックのタイムポインタが同期されます。

## 途中から演奏する `PlayFrom`

長い曲の途中だけを試聴したいときに使います。
指定位置より前の音符は出力されませんが、音色やCCなどの設定は反映されます。

```
PlayFrom(5:1:0)     // 5小節目から演奏
PlayFromHere        // 現在位置から演奏
?                   // PlayFromHere と同じ
```

| コマンド | 別名 |
|---|---|
| `PlayFrom(位置)` | `PLAY_FROM` |
| `PlayFromHere` | `PLAY_FROM_HRER` `?` |

## 移調

| コマンド | 別名 | 内容 |
|---|---|---|
| `KeyShift(n)` | `Key` `KEY` `KeyShift` | 曲全体のキーシフト(半音単位) |
| `TrackKey(n)` | `TR_KEY` | カレントトラックだけのキーシフト |
| `UseKeyShift(on/off)` | | キーシフトを有効にするかどうか |

`KeyShift` と `TrackKey` は加算されます。

```
n$3C                    // ノート番号60
KeyShift(1) TrackKey(1)
n$3C                    // ノート番号62 (1 + 1 = 2半音上)
```

計算式の中では `KEY` `KEY_SHIFT` で現在のキーシフト値を、
`TR_KEY` `TrackKey` でトラックごとのキーシフト値を取得できます。

## 曲の終わり `End`

`End` (または `END`) 以降はコンパイルされません。書きかけの部分を一時的に無効にできます。

```
cdef
End
gab     // ここは演奏されない
```

`End` 以降のテキストはMMLとして解釈されないため、メモ書きを残しておくこともできます。

```
cdef
End
ここから下はメモ。MMLとして読まれない。
```

また、`End` を読み取った時点で、それ以降の演奏(MIDIへの変換)も中断します。
ループ・条件分岐・マクロ・ユーザー定義関数の中に書いた場合も、曲全体の実行が止まります。

```
[4 c End d]  // cが1回鳴るだけで、以降は実行されない
e            // ここも演奏されない
```

```
TR(1) cdef
End
TR(2) gab    // 別のトラックも演奏されない
```

| 命令 | 別名 |
|---|---|
| `End` | `END` |

なお、`EndPoint` のように英数字が続く場合は `End` 命令とみなされません(変数名などに使えます)。
