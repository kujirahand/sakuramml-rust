# MIDIイベントデータの上限

短いMMLでも、繰り返しやCC・ピッチベンドの連続書き込みによって、非常に多くの
MIDIイベントを生成できます。ブラウザやコマンドライン版が過剰なメモリやCPU時間を
消費しないように、生成中のイベントデータには上限があります。

## 既定値

既定の上限は3MiB（3,145,728バイト）です。上限は曲全体で共有され、複数トラックの
イベントも合計されます。上限を超えるイベントは追加されず、コンパイルは中断されます。
エラーメッセージとともに、上限へ達する直前までのイベントを収めたMIDIデータが返されます。

イベントの大きさは、生成されるMIDIデータを基準に保守的に見積もります。
音符は後から生成されるNoteOffも含めて数え、SysEx・メタイベント・SMF直接書き込みは
可変長データも数えます。

上限を超えると、次の形式のエラーが記録されます。

```text
[ERROR](行番号) MIDI event data exceeds max_event_bytes (3145728)
```

## WebAssembly版

WebAssembly版の上限は3MiB固定です。MMLやJavaScriptから変更するAPIはありません。

## コマンドライン版

コマンドライン版では、`--max-event-bytes` に0以上の整数を指定して上限を変更できます。

```sh
sakuramml --max-event-bytes 10485760 song.mml song.mid
```

上限超過時は部分的なMIDIファイルを保存したうえで終了コード1となります。このオプションは、
内容と生成量を確認できる信頼済みのMMLにだけ使用してください。
