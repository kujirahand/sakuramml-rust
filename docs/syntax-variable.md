# 変数の代入・参照とMML展開

[← 目次に戻る](syntax.md)

サクラの変数には、計算式で値を扱う用途と、文字列をMMLとして展開する用途があります。
この2つは処理方法が異なります。

| 用途 | 例 | 処理 |
|---|---|---|
| 値の参照 | `TR(N)`、`Tempo(BPM)` | 実行時に変数の値を評価する |
| MML文字列の展開 | `Str A={cde}`の後に`A` | 文字列をMMLとして再解析して実行する |

## 変数の宣言

変数名は大文字またはアンダースコアで始めます。
予約語やコマンド名と同じ名前は使えません。

```sakura
Int A = 100         // 整数
Str S = {cde}       // 文字列、MMLの断片
Array B = (1,2,3)   // 配列
```

| コマンド | 別名 | 内容 |
|---|---|---|
| `Int 名前 = 値` | `INT` | 整数変数を定義する |
| `Str 名前 = 値` | `STR` | 文字列変数を定義する |
| `Array 名前 = (...)` | `ARRAY` | 配列を定義する |

初期値を省略した宣言も書けます。

```sakura
Int A
A = 100
```

## 代入と参照

変数への代入では、右辺を計算式として評価してから値を保存します。

```sakura
Int A = 1
A = A + 2
Print(A)            // 3
```

インクリメントとデクリメントも使用できます。

```sakura
A++
A--
```

現在の実装では、宣言されていない大文字始まりの名前にも`A=1`の形で代入できます。
ただし、変数の種類と意図を明確にするため、通常は`Int`、`Str`、`Array`で宣言してから使います。

### 値の種類

内部では、整数、文字列、真偽値、配列、ユーザー定義関数、値なしを区別しています。
ただし、`Int`、`Str`、`Array`は厳密な静的型ではありません。
再代入時の型検査は限定的なので、宣言時と同じ種類の値を代入することを推奨します。

文字列と数値を`+`で加算した場合は、文字列として連結します。

```sakura
Str A = {c}
Int B = 4
Str C = A + B
Print(C)            // c4
```

### 配列の参照

配列全体は変数名、要素は`名前(添字)`で参照します。添字は0から始まります。

```sakura
Array A = (10,20,30)
Print(A)            // (10,20,30)
Print(A(0))         // 10
Print(SizeOf(A))    // 3
```

配列の範囲外を参照すると実行時エラーになります。
現在の実装には、`A(0)=100`のような配列要素への代入処理はありません。

### 未定義変数の参照

計算式やMMLコマンドの引数で未定義変数を参照すると、`Undefined: 変数名`という警告を出します。
互換性のため処理は継続し、内部的には値なしとして扱われます。
数値へ変換すると`0`、文字列へ変換すると空文字になります。
一方、未定義の名前をMML命令として単独で書くと、未定義コマンドとして扱われます。

意図しない値を見逃しやすいため、参照前に変数を宣言・代入してください。

## MMLコマンドの引数として参照する

式を引数として受け取るMMLコマンドには、変数や計算式を渡せます。

```sakura
Int TrackNo = 2
Int Speed = 140
Int Instrument = 74

TR(TrackNo)
Tempo(Speed)
@(Instrument)
cdef
```

`TR`、`CH`、`Tempo`、`Key`、`Voice`、`@`などは、引数を実行時に評価します。
計算式も使用できます。

```sakura
Int Base = 100
Tempo(Base + 20)
```

音符番号、ピッチベンド、オクターブ、音量、ゲート、タイミングにも変数を指定できます。

```sakura
Int NoteNo = 60
Int Bend = 100
Int Oct = 5
Int Vel = 90
Int Gate = 80
Int Timing = -3

n(NoteNo)
PB(Bend)
o(Oct) v(Vel) q(Gate) t(Timing)
```

これらの値は命令を実行する時点で参照されます。
一方、`l`は`l4`や`l8`のような音長文字列を直接解析するため、一般的な変数式には対応していません。
音長へ変数値を埋め込む場合は、後述する引数付き文字列マクロを使います。

## 文字列変数をMMLとして展開する

`Str`変数をMML命令の位置に単独で書くと、その内容をMMLとして実行します。

```sakura
Str Melody = {o5 l8 cdef}
Melody
```

展開時には、次の順序で処理します。

1. 現在の変数スコープから文字列を取得する
2. 文字列をMMLとして再び字句解析する
3. 生成されたトークンをその場で実行する

単純な文字列置換ではなく、保存された文字列をMMLソースとして再解析する処理です。
展開したMMLによるオクターブ、音量、テンポなどの状態変更は、その後にも残ります。

状態を局所化したい場合は、マクロ本文で`Sub`を使います。

```sakura
Str Melody = {Sub{o5 l8 cdef}}
Melody
```

### `#`形式のマクロ

`#名前={...}`も文字列変数によるMML展開として使用できます。

```sakura
#Melody = {o5 l8 cdef}
#Melody
```

`Str Melody`と`#Melody`は同じ用途に使えますが、内部の変数名としては`Melody`と`#Melody`は別の名前です。

### 使用位置による違い

文字列変数を単独のMML命令として書いた場合だけ、MMLとして再解析します。
計算式の中では通常の文字列値として参照します。

```sakura
Str A = {cde}

A                   // MMLとして演奏する
Print(A)            // 文字列「cde」を表示する
Str B = A + A
Print(B)            // cdecde
```

## 引数付き文字列マクロ

マクロ本文の`#?1`、`#?2`、`#?3`などを、呼び出し時の引数で置換できます。

```sakura
Str Phrase = {
    o#?1
    v#?2
    cdef
}

Int Oct = 5
Int Vel = 100
Phrase(Oct, Vel)
```

この例では、実行時に概念上、次のMMLを生成して再解析します。

```sakura
o5
v100
cdef
```

この方法は、`l`のように直接の変数指定に対応していない記法や、MML断片そのものを組み立てる場合に利用できます。

MMLそのものを文字列引数として渡すこともできます。

```sakura
Str Repeat = {[2 #?1]}
Repeat({cde})
```

引数はカッコと波カッコのどちらでも渡せます。

```sakura
Str SetOctave = {o#?1}
SetOctave(5)
SetOctave{4}
```

置換は文字列として行われます。一般的な`${変数}`のような補間構文はありません。
たとえば`Str X={oOct c}`と書いても、`Oct`は自動的に変数値へ置換されません。

## 関数内でのMML展開

ユーザー定義関数の`Str`引数も、関数本体で単独記述するとMMLとして展開できます。

```sakura
Function PlayBody(Str Body) {
    Body
}

PlayBody({o5 l8 cdef})
```

関数呼び出し時にはローカルスコープを作成します。
変数参照は、現在のローカルスコープから外側のスコープへ順番に検索します。

```sakura
Int C = 100

Function F(Int N) {
    Int C = N
    Print(C)         // ローカル変数
}

F(1)
Print(C)            // グローバル変数の100
```

`Int`、`Str`、`Array`による宣言は、常に現在のスコープへ新しい変数を作ります。
一方、通常の代入と`++`、`--`は、内側から外側へ検索して最初に見つかった既存変数を更新します。
見つからない場合は、現在のスコープへ新しい変数を作ります。

```sakura
Int A = 10

Function Add() {
    A = A + 1       // 外側のAを更新する
    Int B = 1       // Bは関数のローカル変数
}

Add()
Print(A)            // 11
```

関数の省略可能な引数では、デフォルト値に変数を指定できます。
デフォルト値は関数の呼び出し時に参照されます。

```sakura
Int Base = 7
Function F(Int X=Base) {
    Print(X)
}
F()                 // 7
```

## `Play`での展開

`Play`は、文字列変数に保存したMMLを複数のトラックへ割り当てて実行します。

```sakura
Str AA = {o5 l4 cdef}
Str BB = {o3 l1 c}
Str DD = {CH(10) l8 n36 n38 n36 n38}
Play(AA, BB, DD)
```

第1引数をトラック1、第2引数をトラック2という順で展開します。

## 実装上の注意点

- MML展開は文字列を再字句解析して実行するため、構文エラーは展開時に検出されます。
- `#?1`などの引数展開は型を保った埋め込みではなく文字列置換です。
- 展開されたMMLは呼び出し元の演奏状態を変更できます。
- 数値変数の直接指定に対応するかどうかは、各MMLコマンドの引数解析方法によって異なります。
- `A={...}`形式の直接代入も、命令を実行した時点で有効になります。条件分岐で実行されなかった代入が外側へ漏れることはありません。
- 文字列の一部は`S.s({検索文字列},{置換文字列})`で置換できます。

```sakura
A={c} A
A={d} A             // c、dの順で演奏する

A={c}
If(False) { A={d} }
A                   // cを演奏する
```
