# 先行指定(リザーブ)

「先行指定」は、音量やコントロールチェンジなどの値を**あらかじめまとめて予約**しておく
仕組みです。命令のうしろに `.` を付けて指定します。

```
v.onNote(120,80,100,80) cdef       // 音符ごとにベロシティを切り替える
M.onTime(0,127,!1) l8 cccccccc     // 全音符の間にモジュレーションを0から127へ
```

対象となるのは、音符属性の `v` `q` `t` `o` `l` と、コントロールチェンジ・
ピッチベンド(`CC` `y` `M` `P` `EP` などの名前付きコマンド、`PB` `p`)です。

先行指定は、`v100` `M(0)` のように**値を直接指定すると解除**されます。

## 対応表

| 書き方 | 音符属性 `v` `q` `t` `o` `l` | CC・ピッチベンド |
|---|---|---|
| `.onNote(v1,v2,...)` / `.N(...)` | ○ | ○ |
| `.onTime(low,high,len,...)` / `.T(...)` | ○ | ○ |
| `.onCycle(step,v1,v2,...)` / `.C(...)` | ○ | ○ |
| `.onNoteWave(low,high,len,...)` / `.W(...)` | × | ○ |
| `.onNoteWaveEx(low,high,len,...)` / `.WE(...)` | × | ○ |
| `.onNoteWaveR(low,high,len,...)` / `.WR(...)` | × | ○ |
| `.Sine(type,low,high,len,times)` | × | ○ |
| `.onNoteSine(type,low,high,len,times)` | × | ○ |
| `.Random(n)` | ○ | ○ |
| `.Range(low,high)` | ○ | ○ |
| `.Delay(n)` | ○ | ○ |
| `.Repeat(on/off)` | ○ | ○ |
| `.Frequency(n)` | × | ○ |
| `.Max(n)` | `v` `q` のみ | × |

`.Max` は先行指定ではなく、`v` `q` の**値の上限を変える設定**です。

## 音符属性(`v` `q` `t` `o` `l`)の先行指定

すべての音符属性で、次の指定を共通して使えます。

| 書き方 | 内容 |
|---|---|
| `.onNote(v1,v2,...)` / `.N(...)` | 音符ごとに値を順番に切り替える |
| `.onTime(low,high,len,...)` / `.T(...)` | 時間経過に沿って値を推移させる |
| `.onCycle(step,v1,v2,...)` / `.C(...)` | `step` ステップごとに値を切り替える(解除するまでくり返す) |
| `.Random(n)` | 値を n の幅でランダムにばらつかせる(おおよそ ±n/2) |
| `.Range(low,high)` | 値に下限と上限を設定する |
| `.Delay(n)` | `.onTime` `.onCycle` の開始位置を n ステップ遅らせる |
| `.Repeat(on/off)` | `.onNote` が末尾まで進んだあと、先頭に戻ってくり返すか |
| `.Max(n)` | 値の上限を変更する(`v` `q` のみ) |

`.Random` `.Range` `.Max` は、先行指定を使っていないときの値にも効きます。

```
l.Random(8) l4 cccc      // 音長を96ステップ前後でばらつかせる
o.Range(4,6) o8 c        // オクターブが6に収まる
```

```
v.onNote(50,120,80,120) l4 cccc gggg
v100                                 // 先行指定の解除
q.onTime(10,120,!1) l8 cccccccc dddddddd
t.onCycle(!16,0,8) l16 cccc cccc     // 16分音符ごとにハーフシャッフル
o.onNote(4,5,6) cde                  // 音符ごとにオクターブを切り替える
l.onNote(!4,!8,!8) cde               // 音符ごとに音長を切り替える
v.Max(100) v127 c                    // ベロシティの上限を100にする
q.Range(30,80) q.Random(40) l8 cdef  // ランダムなゲートを30〜80に収める
```

`.onCycle(step, v1, v2, ...)` は時間ベースの指定です。
`t.onCycle(!16,0,8)` は `t.onTime(0,0,!16, 8,8,!16)` を無限にくり返したものと同じ意味になります。
長い音符の途中や休符の間でも、周期は止まらずに進みます。

サブベロシティ `v__n` にも `.onTime` `.onNote` `.onCycle` `.Random` を使えます。
詳しくは[サブベロシティ](syntax-note.md#サブベロシティ-v__n)を参照してください。

> `v` `q` `t` `o` `l` では `.onNoteWave` 系は使えません(エラーになります)。
> 音符の中で音量を波形状に変化させたい場合は、ベロシティ(`v`)ではなく
> エクスプレッション(CC#11)の `EP.onNoteWave(...)` を使ってください。

## コントロールチェンジ・ピッチベンドの先行指定

CCやピッチベンドを、時間や音符に合わせて自動的に連続書き込みできます。
`M` `P` `EP` などの名前付きコマンド、`CC(番号)` `y(番号)`、ピッチベンドの `PB` `p` で使えます。

### `.onTime(low, high, len, ...)` / `.T(...)`

指定した長さ `len` をかけて、値を `low` から `high` へ変化させます。
3つ組を繰り返して書くと、続けて変化させられます。
2組目以降は、直前の組の `len` が経過した位置から始まります。

```
v.onTime(0,127,!1) l8 cccccccc      // 全音符の間に0→127
M.onTime(0,120,!2)
PB.onTime(-8192,0,!4)
PB.T(-8192,0,!8, 0,8191,!8)        // 2つの区間を順番に変化
p.onTime(0,127,!1)
y1.onTime(0,100,!1)
```

`!1` は全音符、`!4` は4分音符の長さ(ステップ数)です。

#### 配列変数・配列式による先行指定

`.onTime` や `.onNote`, `.onCycle` などの引数には、配列変数や配列式を渡すことができます。配列要素は順番に展開されて解釈されます。

```sakura
Array m = (10,10,!16);
Array A = (100,100,!16);
q.onTime(m,A,m,m,A,m,A,A); // 配列要素が順に展開されます
```

また、配列の結合 `A = (A, B, C)` も要素が平坦化（1次元化）されて結合されます。

### `.onNote(v1, v2, v3, ...)` / `.N(...)`

音符を書き込むたびに、値を順番に切り替えます。

```
M.onNote(0,20,40,20) cdef
v.onNote(120,80,100,80) cdef
t.onNote(0,-2,0,2) cdef
```

日本語では「音量予約120,50」のように「予約」で指定できます。

### `.onCycle(step, v1, v2, ...)` / `.C(...)`

`step` ステップごとに、値を順番に切り替えます。解除するまでくり返します。

```
p.onCycle(!4,0,127) l8 [16 c]      // 4分音符ごとに 0, 127 を交互に書き込む
```

### `.onNoteWave(low, high, len, ...)` / `.W(...)`

音符を鳴らし始めるたびに、その音符の先頭を起点として `.onTime(low, high, len, ...)`
と同じ波形を書き込みます。CC系のコマンド(`M` `P` `EP` `y(番号)` など)と、
ピッチベンド(`PB` `p`)で使えます。

```
M.onNoteWave(0,60,!4) l4 cdef     // 音符ごとにモジュレーションを0→60へ
PB.onNoteWave(-4000,4000,!4) l4 cd // 音符ごとにピッチベンドを上げていく
```

- タイ・スラー(`c&d`)でつないだ音符では、先頭の音符で1回だけ書き込みます。
- 和音(`'ceg'`)では、和音全体で1回だけ書き込みます。
- `M(値)` や `PB(値)` のように値を直接指定すると、予約は解除されます。

### `.onNoteWaveEx(low, high, len, ...)` / `.WE(...)`

`.onNoteWave` と同じですが、波形の長さを**音符の長さに合わせて伸縮**させます。
`len` の比率だけが意味を持つので、音符の長さが変わっても同じ形の波形になります。

```
M.onNoteWaveEx(0,0,!4,0,96,!8) l4 cdef   // 音符ごとに、後半でビブラートを深くする
```

ストトン表記の「ビブラート」「方向回す」はこの指定を使っています。

### `.onNoteWaveR(low, high, len, ...)` / `.WR(...)`

音符が鳴っている間、波形をくり返し書き込みます。

```
M.onNoteWaveR(0,120,!8) l2 c       // 2分音符の間、8分音符の波形を4回くり返す
```

### `.Sine(type, low, high, len, times)`

正弦波を1回だけ書き込みます。`times` は繰り返し回数(省略時は1)です。

| `type` | 内容 |
|---|---|
| 0 | `low` → `high` → `low` と1周する正弦波 |
| 1 | `low` から `high` へ上がる 1/4 周期の正弦波 |
| 2 | `high` から `low` へ下がる 1/4 周期の正弦波 |

```
M.Sine(0,0,100,!1,2) c1            // 全音符の長さの正弦波を2回書き込む
```

### `.onNoteSine(type, low, high, len, times)`

音符を鳴らすたびに `.Sine` と同じ波形を書き込みます。

### `.Frequency(n)`

`.onTime` `.onNoteWave` などが値を書き込む間隔(ステップ数)を指定します。
コントロールチェンジとピッチベンドで別々に設定できます。

- CC系の初期値は 4 ステップおき(`CC.Frequency(n)` はトラック内のすべてのCCに効きます)
- ピッチベンドの初期値は `timebase/32` ステップおき(`PB` と `p` で設定を共有します)

```
PB.Frequency(24) PB.onTime(-8192,8191,!4) c   // 24ステップおきに書き込む
```

### `.Delay(n)`

先行指定が書き込む位置を、n ステップ遅らせます。

```
M.Delay(48) M.onTime(0,127,!4) c   // 48ステップ遅れて書き込みが始まる
```

### `.Range(low, high)`

書き込む値に下限と上限を設定します。

```
M.Range(0,50) M.onTime(0,127,!1) c1   // 0〜50の範囲に収まる
```

### `.Repeat(on/off)`

`.onNote` の値を使い切ったあと、先頭に戻ってくり返すかどうかを指定します。
初期値は `off` です。

```
M.onNote(1,2) M.Repeat(on) l4 cdef    // 1, 2, 1, 2
```

### `.Random(n)`

書き込む値をランダムにばらつかせます。
音符属性(`v` `q` `t` `o` `l`)とCC・ピッチベンドの両方で使えます。

### 先行指定が重なったとき

`.onNoteWave` の `len` が音符より長い場合や、`.onTime` の書き込み範囲に
あとから別の先行指定を書いた場合、同じ番号のCC(またはピッチベンド)の
書き込みが時間的に重なります。このとき、**あとから指定したほうが優先**され、
重なった範囲にある古い書き込みは削除されます。

```
M.onNoteWave(0,127,!2) l4 cd
// 1音符目の波形のうち、2音符目と重なる後半は消え、2音符目の波形に置き換わる
```

重なっていない範囲の書き込みはそのまま残ります。
また、**直前と同じ値は書き込まれません**(無駄なイベントを減らすため)。

**タイ・スラーと同時に指定した場合は、タイ・スラーが優先されます。**
`Slur(0)`(グリッサンド)や `Slur(1)`(ベンド)は、つないだ音符の範囲を
ピッチベンドで表現するため、その範囲の `PB.onNoteWave` は書き込まれません。

```
BR(2) Slur(0) PB.onNoteWave(-2000,0,!4) l4 c&d e
// c&d はグリッサンドだけになり、独立した音符 e には波形が書き込まれる
```

同じ音程をつないだだけのタイ(`c&c`)や、ベンドを使わない `Slur(2)`(ゲート) /
`Slur(3)`(アルペジオ)では、ピッチベンドが書き込まれないため波形はそのまま残ります。

> `v` `q` `t` `o` `l` で使えないコマンド(`v.onNoteWave` など)や、
> 解釈できない `.` 付きの指定を書くと、エラーとして報告されます。
> `M.Delay(10)` のような指定が、無言で `M(10)` に化けることはありません。
