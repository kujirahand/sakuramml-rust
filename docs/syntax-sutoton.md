# ストトン表記(日本語表記)

[← 目次に戻る](syntax.md)

サクラでは、MMLを日本語で書けます。これを「ストトン表記」と呼びます。
コンパイルの一番はじめに、日本語の単語が対応する英語のMMLへ置き換えられます。

```
音階4 ドレミファソラシ↑ド↓シラソファミレド
// ↓ 変換後
o4 cdefgab>c<bagfedc
```

英語のMMLと混ぜて書くこともできます。

```
トラック1 チャンネル1 音符1 ドミソー
TR=1 CH=1 l1 ceg^
```

## 音名・休符

| 表記 | 変換結果 | 意味 |
|---|---|---|
| ド / ど | `c` | 音名 |
| レ / れ | `d` | 音名 |
| ミ / み | `e` | 音名 |
| フ / ふ | `f` | 音名(「ファ」の「ァ」は無視される) |
| ソ / そ | `g` | 音名 |
| ラ / ら | `a` | 音名 |
| シ / し | `b` | 音名 |
| ン / ん | `r` | 休符 (例) ドーーン レンレー |
| ッ / っ | `r` | 休符 (例) ドーーッ レッレー |
| ー | `^` | タイ。音を伸ばす |

イロハ表記も使えます。

| 表記 | 変換結果 |
|---|---|
| イ | `a` |
| ロ | `b` |
| ハ | `c` |
| ニ | `d` |
| ホ | `e` |
| ヘ | `f` |
| ト | `g` |
| 変 | `-` (フラット。例: イ変) |
| 嬰 | `+` (シャープ) |

## 記号

| 表記 | 変換結果 | 意味 |
|---|---|---|
| ↑ / 上 | `>` | オクターブを1つ上げる |
| ↓ / 下 | `<` | オクターブを1つ下げる |
| ‘ | `` ` `` | 次の音符だけオクターブを1つ上げる |
| 「 | `'` | 和音はじめ |
| 」 | `'` | 和音おわり |
| 【 | `[` | 繰り返しはじめ |
| 】 | `]` | 繰り返しおわり |
| ♭ | `-` | フラット |
| ♯ | `#` | シャープ |
| − | `-` | マイナス |

```
音符1「ドミソ」
【4 ドレミファ】
```

## 音長

| 表記 | 変換結果 |
|---|---|
| 全音符 | `l1` |
| 二分音符 | `l2` |
| 四分音符 | `l4` |
| 八分音符 | `l8` |
| 十六音符 | `l16` |
| 付点四分音符 | `l4.` |
| 音長 / 音符 | `l` |

```
音符16 ドレミファ
```

## 演奏パラメータ

| 表記 | 変換結果 | 意味 |
|---|---|---|
| 音階(数値) | `o` | 音階。初期値5、範囲0～10 |
| 音量(数値) | `v` | 音量(ベロシティ)。初期値100、範囲0～127 |
| ゲート(割合) | `q` | 発音時間の割合(百分率) |
| 音色(番号) | `@` | 音色を設定する |
| テンポ(数値) | `Tempo=` | テンポ。初期値120 |
| テンポ改(...) | `TempoChange=` | テンポを推移的に変更する |
| トラック(番号) | `Track=` | トラック番号 |
| チャンネル(番号) | `Channel=` | チャンネル番号(1～16) |
| 拍子 分子,分母 | `System.TimeSignature=` | 拍子を設定する |
| 調#(音符) | `System.KeyFlag` | 臨時記号(調号)を設定する。例: 調＃（ドファ） |
| 連符{音名}[音長] | `Div` | 3連符・5連符などを表す |
| 時間(小節:拍:ステップ) | `Time` | タイムポインタを移動する |
| 演奏位置(小節:拍:ステップ) | `PlayFrom` | 曲の途中から演奏する |
| ここから演奏 | `PlayFrom(Time);` | 現在位置から演奏する |
| 読む(ファイル名) | `Include` | 外部定義ファイルを読み込む(未実装) |

```
テンポ120 音階5 音量110 ゲート90
連符{ドレミ}4
時間（４：１：０）
```

全角の数字・記号は半角に変換されます。

## 先行指定・曖昧さ

| 表記 | 変換結果 | 意味 |
|---|---|---|
| (コマンド)予約(v1,v2,...) | `.onNote=` | コマンドの値を音符ごとに予約する |
| (コマンド)曖昧さ(数値) | `.Random=` | 値をランダムにばらつかせる |
| 音量予約 | `v.onTime=` | 音量を時間に沿って変化させる |

```
音量予約(0,127,!1) 八分音符 ドドドドドドドド
音量曖昧さ80 【ドレミソ】
```

## 曲情報

| 表記 | 変換結果 | 意味 |
|---|---|---|
| 曲名{"文字列"} | `TrackName=` | 曲名を埋め込む |
| 作者{"文字列"} | `Copyright=` | 著作権情報を埋め込む |
| コメント{"文字列"} | `MetaText=` | コメントを埋め込む |

```
曲名{"テスト"}
作者{"クジラ飛行机"}
```

## 効果

| 表記 | 変換結果 | 意味 |
|---|---|---|
| 音源初期化 | `System.MeasureShift(1);ResetGM;Time(1:1:0);TrackSync;` | 音源を初期化する |
| 大きく / クレッシェンド | `Cresc=` | 音量(EP)をだんだん大きくする |
| 小さく / デクレッシェンド | `Decresc=` | 音量(EP)をだんだん小さくする |
| 音量戻す | `EP(127)` | 音量(EP)を最大値に戻す |
| 方向左 | `P(0)` | 音を左から出す |
| 方向左前 | `P(32)` | 音を左前から出す |
| 方向前 | `P(64)` | 音を正面から出す |
| 方向右前 | `P(96)` | 音を右前から出す |
| 方向右 | `P(127)` | 音を右から出す |
| 方向回す | `P.onNoteWaveEx(...)` | ステレオの左右を回す(現在は未対応) |
| ビブラート | `M.onNoteWaveEx(...)` | 推移的なビブラートをかける(現在は未対応) |
| ビブラートオフ | `M(0)` | ビブラートをやめる |
| ペダル | `y64,127;` | ダンパーペダルを踏む |
| 放す | `y64,0;` | ダンパーペダルを放す |

> 「方向回す」「ビブラート」は `.onNoteWaveEx` を使うため、
> Rust版では警告が出て無視されます。

## リズム表記

`リズム` (= `Rythm`) モードでは、ひらがな1文字でドラムを打ち込めます。

| 表記 | 変換結果 | 音 |
|---|---|---|
| ず | `n36,` | バスドラム |
| た | `n38,` | スネアドラム |
| つ | `n42,` | ハイハット(クローズ) |
| ち | `n46,` | ハイハット(オープン) |
| ぱ | `n49,` | シンバル |
| と | `n50,` | Lowタム |
| む | `n47,` | Midタム |
| ろ | `n43,` | Highタム |
| く | `n44,` | ドラム |

## ストトン表記の追加定義

`~{名前}={値}` と書くと、独自のストトン表記を追加できます。

```
~{じゅー}={c}
ドレミじゅーレミ
// => cdecde
```

既存の表記を上書きすることもできます。

```
~{ど}={c}
```
