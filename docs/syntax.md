## MMLの基本

MMLは、楽譜をテキストで表す記法です。もっとも短い例は次のようになります。

```
cdefgab
```

これで「ドレミファソラシ」が鳴ります。日本語(ストトン表記)でも書けます。

```
ドレミファソラシ
```

コマンドを付けて、音の高さ・長さ・強さを指定します。

```
o4 l8 q90 v110 cdefgab>c
```

- `o4` … オクターブ4
- `l8` … 以降の音符の長さを8分音符に
- `q90` … ゲートタイム(音の長さに対する実際の発音時間)を90%に
- `v110` … ベロシティ(音の強さ)を110に
- `>` … オクターブを1つ上げる

## コンパイルの流れ

サクラは次の順序でMMLをMIDIファイルに変換します。

1. **ストトン変換** (`sutoton.rs`) … 日本語表記を英語のMMLに置き換える
2. **字句解析** (`lexer.rs`) … MMLをトークンに分割する
3. **実行** (`runner.rs`) … トークンを順に実行してイベントを生成する
4. **MIDI出力** (`midi.rs`) … イベントをSMF(Standard MIDI File)として書き出す

MMLは「上から順に実行されるプログラム」です。`o4` と書けばそれ以降の音符に効き、
`Int A = 3` と書けば変数が定義されます。ループや条件分岐も使えます。

## コマンドの書式

### 1文字コマンド(小文字)

小文字1文字は音符やパラメータ指定に割り当てられています。

```
c d e f g a b   音名
n               番号指定の音符 (ex) n60
r               休符
l o p q v t y   音長 / オクターブ / ピッチベンド / ゲート / ベロシティ / タイミング / CC
```

### 複数文字コマンド(大文字始まり)

大文字で始まる単語は命令(システム関数)です。引数はカッコか `=` で与えます。
どちらの書き方でも同じ意味になります。

```
Tempo(120)
Tempo=120
TEMPO(120)
```

多くのコマンドには、大文字だけの別名や短縮名があります(例: `Track` / `TRACK` / `TR`)。

### 数値の書き方

| 書き方 | 意味 |
|---|---|
| `120` | 10進数 |
| `$7F` | 16進数(サクラv2互換の書式) |
| `0x7F` | 16進数 |
| `0o17` | 8進数 |
| `!4` | 音長をステップ数(Tick)に変換した値。`!4` は4分音符の長さ。先行指定(`.onTime` など)や `o` `v` `q` `t` の引数で使える(一般の計算式では使えない) |
| `変数名` | 定義済みの変数を参照(大文字始まり) |

### コメント

| 書き方 | 意味 |
|---|---|
| `// ...` | 行コメント |
| `/// ...` | 行コメント(デバッグ用) |
| `## ...` `# ...` `#- ...` | 行コメント |
| `/* ... */` | 範囲コメント |

`;` と `|` と空白・タブ・改行は区切り文字として読み飛ばされます。
`|` は小節の区切りを見やすくするために使えます。

```
c d e f | g a b > c
```

## 初期値

| 項目 | 初期値 | 備考 |
|---|---|---|
| タイムベース | 96 | 4分音符の分解能。`TimeBase(n)` で変更(48未満は48に補正) |
| 音長 `l` | 4分音符 | タイムベースと同じステップ数 |
| オクターブ `o` | 5 | 範囲 0～10 |
| ベロシティ `v` | 100 | 範囲 0～127 |
| ゲート `q` | 90 | 百分率 |
| テンポ | 120 | |
| 拍子 | 4/4 | |
| `(` `)` の増減幅 | 8 | `System.vAdd(n)` で変更 |
| `q++` `q--` の増減幅 | 1 | `System.qAdd(n)` で変更 |
| チャンネル | トラック番号と同じ | `TR(1)` なら CH=1 |

## コマンドラインの使い方

```bash
sakuramml test.mml test.mid
```

| オプション | 内容 |
|---|---|
| `(mmlfile) (midifile)` | MMLをMIDIに変換(出力名を省略すると `.mid` を付けた名前になる) |
| `-e`, `--eval` | 文字列として渡したMMLをコンパイルする(出力は `eval.mid`) |
| `-m`, `--dump` | MIDIファイルの内容をダンプする |
| `-d`, `--debug` | デバッグモード(トークンと実行過程を表示) |
| `-v`, `--version` | バージョン表示 |
| `-h`, `--help` | ヘルプ表示 |

```bash
sakuramml --eval "o4l4 cege c1"
```

### ビルド番号

通常のビルドでは、バージョン番号だけを表示します。リリースやCIの成果物を識別したい場合は、
コンパイル時に環境変数 `BUILD_NUMBER` を指定できます。

```bash
BUILD_NUMBER=123 cargo build --release
```

この場合、ヘルプ画面やWeb版のバージョン欄に `build:123` が追加されます。
ビルド番号はリポジトリ内のファイルでは管理しません。

## サクラv1/v2との違い

Rust版では、意図的に仕様を変更した箇所があります。

### ステップ指定は一時的

v1/v2では `l%96` と書くと以降ずっとステップ指定モードになりましたが、
Rust版では `%` は書いたその場所だけに効きます。

```
// 以下の2行は同じ意味
l%96 cde
c4d4e4
```

### 連符の `Div` を省略できる

```
l4 Div{cde} f Div{gab} >c<
l4 {cde} f {gab} >c<
```

### `c0e0g` 形式の和音は非サポート

長さ0を並べる書き方はサポートしません。和音は `'ceg'` を使ってください。

```
'ceg' 'dfa' 'egb' 'ceg'
```

### 未実装のコマンド

以下は現在の実装では動作しません(エラーまたは警告になります)。

- `Include` / `System.Include` … 外部ファイルの読み込み
- `System.q2Add` / `q2Add`
- `l.Random` / `l.onTime` / `o.onTime` / `q.onTime`
- CC系の `.onNoteWaveEx` / `.onNoteWaveR` / `.onCycle` / `.Sine` / `.onNoteSine`
