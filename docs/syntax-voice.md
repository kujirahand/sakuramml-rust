# 音色とMIDI制御

[← 目次に戻る](syntax.md)

音色の指定、コントロールチェンジ(CC)、ピッチベンド、RPN/NRPNなど、
MIDI音源を制御するコマンドです。

## 音色 `@` / `Voice`

```
@番号[,バンクMSB][,バンクLSB]
Voice(番号[,バンクMSB][,バンクLSB])
```

音色番号の範囲は 1～128 です(GM音源の音色番号)。
バンクを指定すると、プログラムチェンジの前に CC#0(MSB)と CC#32(LSB)を書き込みます。

```
@1              // GrandPiano
@25 cde         // NylonGuitar
Voice(1)
```

音色名の定数も使えます。名前で書くと読みやすくなります。

```
@GrandPiano
@(SquareLead)
Voice(Flute)
```

音色名の一覧は [voice.md](../voice.md) を参照してください。
番号体系、Bank Select、MIDIダンプとの対応は [Voice（音色番号）の仕様](voice.md) を参照してください。

| コマンド | 別名 |
|---|---|
| `Voice(n)` | `VOICE` / `@n`(1文字コマンド) |

## コントロールチェンジ

### 汎用の書き方

```
y番号,値            // 1文字コマンド
CC(番号, 値)
ControlChange(番号, 値)
```

```
y1,100          // CC#1 (モジュレーション) に100
CC(1, 100)
y64,127         // ダンパーペダルON
y64,0           // ダンパーペダルOFF
```

| コマンド | 別名 |
|---|---|
| `CC(no, val)` | `CONTROL_CHANGE` `ControlChange` / `y(no),(val)` |

### 名前付きコマンド

よく使うコントロールチェンジには専用の命令があります。

| コマンド | 別名 | CC番号 | 内容 | 範囲 |
|---|---|---|---|---|
| `Modulation(n)` | `M` | CC#1 | モジュレーション(ビブラート) | 0-127 |
| `PortamentoTime(n)` | `PT` | CC#5 | ポルタメントタイム | 0-127 |
| `MainVolume(n)` | `V` | CC#7 | メインボリューム | 0-127 |
| `Panpot(n)` | `P` | CC#10 | パンポット(定位) | 0-64-127 |
| `Expression(n)` | `EP` | CC#11 | エクスプレッション | 0-127 |
| `PortamentoSwitch(n)` | `PS` | CC#65 | ポルタメントのON/OFF | 0-127 |
| `Reverb(n)` | `REV` | CC#91 | リバーブ | 0-127 |
| `Chorus(n)` | `CHO` | CC#93 | コーラス | 0-127 |
| `Variation(n)` | `VAR` | CC#94 | バリエーション | 0-127 |

```
V(100) P(64) EP(120) REV(40)
M=10
```

`v`(小文字)はベロシティ、`V`(大文字)はメインボリュームです。混同しないよう注意してください。

## ピッチベンド

| コマンド | 範囲 | 内容 |
|---|---|---|
| `p値` | 0～64～127 | 1文字コマンド。64が中央 |
| `PitchBend(値)` / `PB(値)` | -8192～0～8191 | 詳細な指定 |
| `BendRange(値)` | 半音単位 | ベンドの効く幅(RPN 0,0) |

別名: `PitchBendSensitivity` `BEND_RANGE` `BR`

```
p64             // 中央
PB(0)
BR(2) PB.onTime(-8192,0,!4) l4 c PB(0) efg^
BR(2) PB.onNoteWave(-4000,0,!4) l4 cdef PB(0)  // 音符ごとにベンドを効かせる
```

## RPN / NRPN

```
RPN(MSB, LSB, 値)
NRPN(MSB, LSB, 値)
```

よく使う設定には専用コマンドがあります。

| コマンド | 種別 | 内容 | 範囲 |
|---|---|---|---|
| `BendRange(n)` / `BR` | RPN 0,0 | ピッチベンドの幅 | 半音単位 |
| `FineTune(n)` | RPN 0,1 | ファインチューン | 0-64-127 (-100～+99.99セント) |
| `CoarseTune(n)` | RPN 0,2 | 半音単位のチューニング | 40-64-88 (-24～+24半音) |
| `VibratoRate(n)` | NRPN 1,8 | ビブラートの速さ | 0-127 |
| `VibratoDepth(n)` | NRPN 1,9 | ビブラートの深さ | 0-127 |
| `VibratoDelay(n)` | NRPN 1,10 | ビブラートの遅延 | 0-127 |
| `FilterCutoff(n)` | NRPN 1,$20 | フィルターのカットオフ | 0-127 |
| `FilterResonance(n)` | NRPN 1,$21 | フィルターのレゾナンス | 0-127 |
| `EGAttack(n)` | NRPN 1,$63 | アタックタイム | 0-127 |
| `EGDecay(n)` | NRPN 1,$64 | ディケイタイム | 0-127 |
| `EGRelease(n)` | NRPN 1,$66 | リリースタイム | 0-127 |

## 先行指定(連続書き込み)

CCやピッチベンドを、時間や音符に合わせて自動的に連続書き込みできます。
「先行指定」と呼ばれ、命令のうしろに `.` を付けて指定します。

### `.onTime(low, high, len, ...)` / `.T(...)`

指定した長さ `len` をかけて、値を `low` から `high` へ変化させます。
3つ組を繰り返して書くと、続けて変化させられます。
2組目以降は、直前の組の `len` が経過した位置から始まります。

```
v.onTime(0,127,!1) l8 cccccccc      // 全音符の間に0→127
M.onTime(0,120,!2)
PB.onTime(-8192,0,!4)
PB.T(-8192,0,!8, 0,8191,!8)        // 2つの区間を順番に変化
p.onTime(0,127,!1)
y1.onTime(0,100,!1)
```

`!1` は全音符、`!4` は4分音符の長さ(ステップ数)です。

### `.onNote(v1, v2, v3, ...)` / `.N(...)`

音符を書き込むたびに、値を順番に切り替えます。

```
M.onNote(0,20,40,20) cdef
v.onNote(120,80,100,80) cdef
t.onNote(0,-2,0,2) cdef
```

日本語では「音量予約120,50」のように「予約」で指定できます。

### `.onCycle(v1, v2, ...)` / `.C(...)`

値を周期的に切り替えます(`v` `q` `t` `o` `l` で使えます)。

### `.onNoteWave(low, high, len, ...)` / `.W(...)`

音符を鳴らし始めるたびに、その音符の先頭を起点として `.onTime(low, high, len, ...)`
と同じ波形を書き込みます。CC系のコマンド(`M` `P` `EP` `y(番号)` など)と、
ピッチベンド(`PB` `p`)で使えます。

```
M.onNoteWave(0,60,!4) l4 cdef     // 音符ごとにモジュレーションを0→60へ
PB.onNoteWave(-4000,4000,!4) l4 cd // 音符ごとにピッチベンドを上げていく
```

- タイ・スラー(`c&d`)でつないだ音符では、先頭の音符で1回だけ書き込みます。
- 和音(`'ceg'`)では、和音全体で1回だけ書き込みます。
- `M(値)` や `PB(値)` のように値を直接指定すると、予約は解除されます。

> `v` `q` `t` `o` `l` では使えません(エラーになります)。
> 音符の中で音量を波形状に変化させたい場合は、ベロシティ(`v`)ではなく
> エクスプレッション(CC#11)の `EP.onNoteWave(...)` を使ってください。

### `.Frequency(n)`

コントロールチェンジの書き込み頻度を指定します。

### `.Random(n)`

書き込む値をランダムにばらつかせます(`v` `q` `t` `o` で使えます)。

### 先行指定が重なったとき

`.onNoteWave` の `len` が音符より長い場合や、`.onTime` の書き込み範囲に
あとから別の先行指定を書いた場合、同じ番号のCC(またはピッチベンド)の
書き込みが時間的に重なります。このとき、**あとから指定したほうが優先**され、
重なった範囲にある古い書き込みは削除されます。

```
M.onNoteWave(0,127,!2) l4 cd
// 1音符目の波形のうち、2音符目と重なる後半は消え、2音符目の波形に置き換わる
```

重なっていない範囲の書き込みはそのまま残ります。
また、**直前と同じ値は書き込まれません**(無駄なイベントを減らすため)。

> ※ タイ・スラーのグリッサンド(`Slur(0,...)`)が生成するピッチベンドは、
> この置き換えの対象外です。`PB.onNoteWave` と併用すると両方が書き込まれます。

> 未対応: `.onNoteWaveEx` `.onNoteWaveR` `.onCycle`(CC系) `.Sine` `.onNoteSine`
> (これらは警告を出して無視されます)
> また `v` `q` `t` `o` `l` で未対応のコマンド(`v.onNoteWave` など)を書くと、
> 無視されずにエラーとして報告されます。

## フェード・クレッシェンド

| コマンド | 内容 |
|---|---|
| `Fadein(小節数)` | エクスプレッション(CC#11)を0から127へ変化させる |
| `Fadeout(小節数)` | エクスプレッションを127から0へ変化させる |
| `Cresc=len,v1,v2` | だんだん大きくする |
| `Decresc=len,v1,v2` | だんだん小さくする |

別名: `CRESC` `DECRESC`

`Fadein` / `Fadeout` は小節数を指定します。

```
Fadein(1)
Fadeout(1)
```

`Cresc` / `Decresc` は音長と開始値・終了値を指定します。
**カッコではなく `=` に続けて書く**点に注意してください(音長の表記を読み取るためです)。

```
Cresc=1,40,127 l8 cdefgab>c     // 全音符の長さをかけて40から127へ
Cresc=1                          // 値を省略すると 40 → 127
Decresc=1                        // 値を省略すると 127 → 40
```

`len` を省略すると全音符の長さになります。日本語では「大きく」「小さく」と書けます。

```
大きく1,40,127 l8 ドレミファ
```

## 直接的なMIDI出力

| コマンド | 内容 |
|---|---|
| `NoteOn(番号, ベロシティ)` | ノートオンを直接書き込む |
| `NoteOff(番号, ベロシティ)` | ノートオフを直接書き込む |
| `DirectSMF(b1, b2, b3, ...)` | SMFイベントを直接書き込む |

## その他

| コマンド | 内容 |
|---|---|
| `SoundType({名前})` | 音源の種類を設定する (例: `SoundType({pico})`) |
| `DeviceNumber(n)` | デバイス番号を設定する (例: `DeviceNumber=$10`) |
